# Как пользоваться программой (Вариант А: Colab + Drive)

Логика разделена на два этапа:

1. **Запись + расшифровка через Colab** (бесплатно, GPU Google).
2. **Генерация отчёта через GPT-4o-mini** (платно — ~$0.01 за совещание).

## Один раз — настройка

### 1. Положить блокнот в Drive

Открыть в Colab файл `Colab_Транскрипция_совещаний.ipynb` (из этой папки) и сохранить его в свой Google Drive: **File → Save a copy in Drive**. Дальше будете запускать копию из Drive.

### 2. Принять условия pyannote

Зайти под своим аккаунтом HuggingFace и нажать «Agree» на двух страницах:

- https://huggingface.co/pyannote/speaker-diarization-3.1
- https://huggingface.co/pyannote/segmentation-3.0

Без этого диаризация не загрузится.

### 3. Включить GPU в блокноте

В Colab: **Runtime → Change runtime type → Hardware accelerator: GPU (T4) → Save**.

### 4. Заполнить токены

Открыть в блокноте ячейку «Настройки» и подставить:

- `YOUR_HF_TOKEN` — ваш токен HuggingFace (он уже подставлен по умолчанию).
- `OPENAI_API_KEY` — оставить пустым, **если cleanup не нужен** (рекомендуется).
- `CLEANUP_MODE` — `"off"` для экономии токенов.

## Обычное использование (каждое совещание)

```
1. [MeetingAssistant] Записать совещание → стоп.
   → WAV сохранён в G:\Mój dysk\Programming\MeetingAssistant\Recordings\
   → Google Drive автоматически синхронизирует файл в облако (30-90 сек).

2. [Браузер] Открыть свой Colab-блокнот в Drive → Runtime → Run all.
   → Через 5-10 минут (для 2-часового совещания на T4):
     в G:\Mój dysk\Programming\MeetingAssistant\Transcripts\<тоже_имя>.txt
     появится текст в формате "Speaker 0: ...\nSpeaker 1: ...".

3. [MeetingAssistant] "📝 Загрузить транскрипт" → выбрать .txt
                       "Загрузить пример"        → выбрать JSON-шаблон отчёта
                       "📄 ОТЧЕТ"                → ~10-30 сек GPT-4o-mini
   → отчёт в Reports/ как .md и final_report.json.
```

## Важные нюансы

- **Если у вас уже есть готовый .txt** (с прошлого совещания, из Colab или из любого источника): просто нажмите «📝 Загрузить транскрипт» — приложение само создаст «обёртку» совещания. Запись и WAV не нужны.
- **Если у вас уже есть готовый WAV** (старая запись): «🎧 Загрузить аудио» → положите WAV в Recordings и прогоните через Colab → «📝 Загрузить транскрипт».
- Бесплатный Colab иногда отказывает в GPU («No backend available»). Подождите 5-30 минут или попробуйте Runtime → Disconnect and delete runtime → Run all.
- Сессия Colab умирает через ~90 минут простоя. Это не страшно — просто Run all снова.

## Стоимость

| Этап                              | Где       | Цена за 2-часовое совещание |
|-----------------------------------|-----------|------------------------------|
| Запись WAV                        | локально  | 0 ₽                          |
| Транскрипция WhisperX + pyannote  | Colab GPU | 0 ₽ (бесплатный T4)          |
| Cleanup `off`                     | —         | 0 ₽                          |
| Cleanup `mini`                    | OpenAI    | ~$0.03                       |
| Cleanup `4o`                      | OpenAI    | ~$0.50                       |
| Генерация отчёта (GPT-4o-mini)    | OpenAI    | ~$0.01                       |

С `CLEANUP_MODE="off"` все ваши $4 на счёте уходят только на отчёты — хватит на ~400 совещаний.

## Что делает блокнот внутри (для понимания)

1. `whisperx.load_model("large-v3", "cuda", "float16")` — загрузка большой модели.
2. `model.transcribe(audio, batch_size=16)` — речь → текст с таймингами.
3. `DiarizationPipeline("pyannote/speaker-diarization-3.1", use_auth_token=...)` — определение, кто говорит, **сам определяет количество спикеров**.
4. `whisperx.assign_word_speakers(...)` — приклеивает метки спикеров к словам.
5. Сборка строк `Speaker N: текст`.
6. (опц.) GPT-cleanup: убирает явные ошибки диаризации, не меняя текст реплик.
7. Сохранение `.txt` в `Transcripts/` (тот же Drive — синхронизация назад на компьютер).
