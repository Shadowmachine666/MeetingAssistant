Что нужно настроить (env) для удалённого режима
В .env добавьте (пример):

TRANSCRIPTION_BACKEND=hf_spaces
HF_SPACES_URL=https://<ваш-space>.hf.space
HF_SPACES_ENDPOINT=/transcribe
HF_SPACES_TOKEN=...   # если Space приватный
SPEAKER_CLEANUP_ENABLED=true
OPENAI_SPEAKER_CLEANUP_MODEL=gpt-4o
MEETING_USE_OPENAI_WHISPER=false
Ожидаемый формат ответа HF Spaces API
POST {HF_SPACES_URL}{HF_SPACES_ENDPOINT} multipart:

file: WAV
diarize: true|false
Response JSON (минимум):

{
  "segments": [
    {"start": 0.0, "end": 1.0, "speaker": "Speaker 0", "text": "Hello"}
  ],
  "language": "ru",
  "plain_text": "..."
}
Если хотите — следующим шагом могу помочь вам быстро сделать HF Space, который возвращает точно этот JSON на базе вашего Colab-кода (WhisperX+pyannote 3.1), чтобы приложение “из коробки” заработало с удалённой обработкой.
