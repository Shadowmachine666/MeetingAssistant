# Структура проекта MeetingAssistant

> Актуализировано под фактическую реализацию (Python + PyQt6). Дата: 2026-07-11.
> Ранее здесь описывалась структура Solution на C#/.NET — она устарела и не
> соответствует коду. Ниже — реальное дерево Python-проекта.

## Дерево каталогов (исходный код)


## Рантайм-папки данных (создаются при работе)

```
MeetingAssistant/
├── Recordings/     # WAV записи совещаний: {timestamp}_meeting_{id8}.wav
│                   # Временные сырые файлы во время записи: <wav>.mic.pcm, <wav>.sys.pcm
│                   # (удаляются после успешного сведения; остаются при сбое/превышении лимита)
│                   # Также временные аудиофрагменты переводов
│
├── Reports/        # Отчёты: {timestamp}_report_{id8}.md
│                   # и {timestamp}_final_report_{id8}.json
│
├── Transcripts/    # Транскрипты .txt (загружаются пользователем из Colab)
│
├── Templates/      # Шаблоны-примеры отчётов (.txt / .docx)
│
├── Logs/           # app_{YYYY-MM-DD}.log (ротация 10 МБ × 5 бэкапов)
│
├── Config/         # meetings.json (сериализация совещаний из MeetingRepository)
│
└── INFO/           # Документация (этот файл и др.)
```

## Конфигурация (`.env`)

Загружается через `python-dotenv`. Основные группы переменных (значения по умолчанию
заданы в коде, если переменная не указана):

```
# OpenAI
OPENAI_API_KEY_1 / _2 / _3   # пул ключей (или единый OPENAI_API_KEY)
OPENAI_BASE_URL              # https://api.openai.com/v1
OPENAI_MODEL                 # gpt-4
OPENAI_TRANSCRIPTION_MODEL   # whisper-1
OPENAI_MAX_TOKENS            # 4000
OPENAI_TEMPERATURE           # 0.7
OPENAI_RETRY_ATTEMPTS        # 3
OPENAI_RETRY_DELAY_MS        # 1000

# Хранилище (пути)
STORAGE_RECORDINGS_PATH      # ./Recordings
STORAGE_REPORTS_PATH         # ./Reports
STORAGE_TEMPLATES_PATH       # ./Templates
STORAGE_TRANSCRIPTS_PATH     # ./Transcripts
STORAGE_LOGS_PATH            # ./Logs

# Аудио (параметры рекордеров)
sample_rate = 44100, channels = 2, microphone_gain, system_gain
```

> Точные имена переменных окружения см. в `main.py::setup_dependencies()` и
> конструкторах `OpenAIClient` / `ApiKeyPool` / `StorageService`.

## Правила именования (фактические в проекте)

- **Файлы/модули**: `snake_case.py` (`meeting_audio_recorder.py`).
- **Классы**: `PascalCase` (`MeetingAudioRecorder`, `MainWindow`).
- **Интерфейсы**: префикс `I` (`IAudioRecorder`, `IMeetingRepository`).
- **Функции/методы**: `snake_case` (`start_recording`, `get_recording_path`).
- **Асинхронные методы сервисов/репозиториев**: обычные `async def` (без суффикса `Async`).
- **Приватные члены**: префикс `_` (`_stream_mix_to_wav`, `_mic_chunks`).
- **Enums**: наследуют `(str, Enum)`, значения — строки (`"Recording"`).

## Тесты

Запуск: `python -m pytest tests/ -q`

Покрытие сфокусировано на самой критичной части — движке записи совещаний:
- сведение источников в стерео (выравнивание длин, гейны, клиппинг);
- потоковое поблочное сведение `.pcm` → WAV;
- регресс `[Errno 22]` (никаких одиночных записей >2 ГБ);
- защита лимита размера WAV (~4 ГБ);
- очистка/сохранение временных `.pcm` при успехе и при ошибке;
- оценщик токенов и сохранение `final_report.json`.
